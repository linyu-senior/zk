**习题 3.4**。选择你喜欢的一个素数 $p$。编写一个 Python 程序，它以一个长度为 $2^\ell$ 的数组（指定了函数 $f : \{0,1\}^\ell \to \mathbb{F}_p$ 的所有求值结果）和一个向量 $r \in \mathbb{F}_p^\ell$ 作为输入，并输出 $\tilde{f}(r)$。

---

### 二、 Python 实现思路

为了完美呼应我们在前面学过的**引理 3.8（动态规划/记忆化表格法）**，这段代码不使用笨拙的独立计算（$O(\ell \cdot 2^\ell)$），而是采用逐层扩展（Doubling）的动态规划思路：

1. **构建基多项式表**：从第 1 维到第 $\ell$ 维，利用上一层的基底前缀乘以当前维度的因子 $(1 - r_i)$ 和 $r_i$，在 $O(2^\ell)$ 时间内生成所有 $2^\ell$ 个 $\chi_w(r)$。
2. **计算向量内积**：将生成的 $\chi_w(r)$ 表与输入的 $f(w)$ 数组进行对应相乘并求和，得到最终的 $\tilde{f}(r)$。

---

### 三、 完整 Python 代码

你可以直接在本地运行这段代码。这里我们选择了素数 $p = 11$，并用教材中练习 3.3 的三元函数数据进行了测试验证。

```python
def compute_mle_eval(p, f_evals, r):
    """
    计算多线性扩展 f_tilde(r)
    :param p: 素数模数 (有限域 F_p 的特征)
    :param f_evals: 长度为 2^l 的列表，包含 f 在布尔超立方体上的所有 2^l 个取值
    :param r: 长度为 l 的向量 (挑战点 r1, r2, ..., r_l)
    :return: 终值 f_tilde(r) 在 F_p 中的结果
    """
    l = len(r)
    assert len(f_evals) == 2**l, "输入数组长度必须为 2^l"

    # 阶段 0：初始化基多项式表，初始只有第 1 维的两个值
    # 对应引理 3.8 的 Stage 1
    r1 = r[0]
    chi_table = [1 - r1, r1]  # 对应 w1=0 和 w1=1 的基底

    # 动态规划构建后续维度的基多项式表 (Stage 2 到 Stage l)
    for i in range(1, l):
        ri = r[i]
        next_table = []
        for val in chi_table:
            # 每一项前缀分别乘以 (1 - ri) 和 ri
            next_table.append((val * (1 - ri)) % p)
            next_table.append((val * ri) % p)
        chi_table = next_table

    # 此时 chi_table 里面装好了所有 2^l 个 chi_w(r)
    # 计算 f_evals 与 chi_table 的内积
    result = 0
    for fw, chi_w in zip(f_evals, chi_table):
        result = (result + fw * chi_w) % p

    return result


# ==========================================
# 测试验证：用 Exercise 3.3 中的三元例子进行测试
# p = 11, f(0,0,0)=1, f(0,1,0)=2, f(1,0,0)=3, f(1,1,0)=4,
#        f(0,0,1)=5, f(0,1,1)=6, f(1,0,1)=7, f(1,1,1)=8
# 挑战点 r = (2, 4, 6)
# ==========================================
if __name__ == "__main__":
    p_prime = 11
    # 按照字典序排列的 8 个顶点求值
    f_values = [1, 5, 2, 6, 3, 7, 4, 8]
    # 对应 f(0,0,0), f(0,0,1), f(0,1,0), f(0,1,1), f(1,0,0), f(1,0,1), f(1,1,0), f(1,1,1)
    # （注：Python 中二进制索引 000, 001, 010, 011, 100, 101, 110, 111 对应上述顺序）

    r_vector = (2, 4, 6)

    ans = compute_mle_eval(p_prime, f_values, r_vector)
    print(f"在域 F_{p_prime} 中，多线性扩展在点 {r_vector} 处的值为: {ans}")

```

运行这段代码，你会发现输出结果正好是 **`0`**，这与我们在前面做 Exercise 3.3 手工推导的结果完美契合！
