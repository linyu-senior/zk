**_轮数与通信复杂度_**。通过直接观察协议描述，GKR 协议包含 $O(d \log S)$ 轮交互，且总通信成本为 $O(d \log S)$ 个域元素。

**_可靠性误差（Soundness Error）_**。GKR 协议的可靠性误差为 $O(d \log(S) / \vert{}\mathbb{F}\vert{})$。可靠性分析的基本思路是：如果证明者在协议开始时对输出值 $C(x)$ 做出了错误的声称，那么为了使验证者被说服并接受，在交互式证明中至少必须发生以下情况中的某一个轮次 $j$：证明者发送了一个单变量多项式 $g_j$，它不同于在这一轮中诚实证明者本应发送的规定多项式 $s_j$，但却满足 $g_j(r_j) = s_j(r_j)$，其中 $r_j$ 是验证者在第 $j$ 轮中随机选择的域元素。

对于对应于求和检验协议内部轮次的 GKR 协议轮次 $j$，$g_j$ 和 $s_j$ 是阶数为 $O(1)$ 的多项式，因此如果 $g_j \neq s_j$，则 $g_j(r_j) = s_j(r_j)$ 的概率（基于 $r_j$ 的随机选择）至多为 $O(1 / \vert{}\mathbb{F}\vert{})$。

在对应于“将归约简化为单点验证”技术的 GKR 协议轮次 $j$ 中，$g_j$ 和 $s_j$ 的阶数至多为 $O(\log S)$，因此如果 $g_j \neq s_j$，其满足 $g_j(r_j) = s_j(r_j)$ 的概率至多为 $O(\log(S) / \vert{}\mathbb{F}\vert{})$。请注意，在整个协议运行过程中，最多有 $d$ 个这样的轮次，因为该技术在电路的每一层中最多应用一次。

通过对协议中的所有轮次应用联合边界（Union Bound），我们得出结论：存在任何一个轮次 $j$ 使得 $g_j \neq s_j$ 却同时满足 $g_j(r_j) = s_j(r_j)$ 的概率至多为 $O(d \log(S) / \vert{}\mathbb{F}\vert{})$。

**_关于可靠性的额外直觉与讨论_**。总之，GKR 协议的证明者首先发送输出门的声称值，从而指定了输出值向量 $W_0$，接着验证者在一个随机点对 $\tilde{W}_0$ 进行求值。类似地，在协议第 $i$ 次迭代结束时，证明者被迫对 $\tilde{W}_i$ 的某一个随机选择的求值做出声明。通过这种方式，证明者逐渐将“对输出层（多线性扩展的某一求值）的声明”，转化为“对输入层的类似声明”，而验证者可以直接在线性时间内检查输入层。

一个常见的误解是，认为“检查证明者对 $\tilde{W}_i$ 随机求值的声明”等同于：在第 $i$ 层中随机选择一个门，然后确认证明者是否正确计算了该门的数值（例如，如果该门是一个乘法门，就检查证明者赋予该门的数值是否确实等于其输入端数值的乘积）。如果这种理解是正确的，那么该协议将不具备可靠性（soundness），因为一个在电路中“篡改”了单个门数值的作弊证明者，只有在那个被篡改的门刚好被随机选中时，才会被验证者抓包。

上述理解是不准确的：这两个过程只有在 $r_i$ 的每一个分量都是从 $\{0,1\}$ 中随机选择（而不是从整个域 $\mathbb{F}$ 中随机选择）时才等价。

事实上，如果第 $i$ 层哪怕只有一个门的数值被损坏，根据施瓦茨-齐佩尔引理（Schwartz-Zippel lemma），$\tilde{W}_i$ 的几乎所有求值结果都必然会发生改变。通过对电路每一层的门数值的多线性扩展编码进行“抽查（spot-checking）”，GKR 验证者能够检测到证明者偏离电路逐门正确计算的任何微小偏差。参见图 4.14 的描绘。

### 4.6.6 Evaluating ̃addi and ̃multi Efficiently(高效求值 $\tilde{\text{add}}_i$ 与 $\tilde{\text{mult}}_i$)

在随机点 $\omega \in \mathbb{F}^{k_i + 2k_{i+1}}$ 处，验证者如何高效地求值 $\tilde{\text{add}}_i$ 和 $\tilde{\text{mult}}_i$ 是一个颇具挑战性的问题。

虽然目前似乎还没有一个清晰的刻画，能够准确界定哪些电路的 $\tilde{\text{add}}_i$ 和 $\tilde{\text{mult}}_i$ 能够在 $O(\log S)$ 时间内完成求值，但绝大多数表现出某种重复结构的电路都满足这一性质。特别是，相关论文 [CMT12, Tha13] 表明，对于各种常见的布线模式和特定电路，这种求值可以在 $O(k_i + k_{i+1}) = O(\log S)$ 的时间内计算出来。这包括计算诸如矩阵乘法（MATMULT）、模式匹配、快速傅里叶变换（FFT），以及流式算法文献中感兴趣的各种问题（如频率矩和不同元素计数，见习题 4.4）。

同样，Holmgren 和 Rothblum [HR18, 第 5.1 节] 指出，只要 $\text{add}_i$ 和 $\text{mult}_i$ 能够在称为“一次读取分支程序（read-once branching programs）”的计算模型中被计算，那么 $\tilde{\text{add}}_i$ 和 $\tilde{\text{mult}}_i$ 就可以在对数时间内于任何期望的点处求值，并观察到这一条件确实涵盖了常见的布线模式。此外，我们将在 4.6.7 节中看到，对于任何以数据并行（data parallel manner）方式运行的电路，$\tilde{\text{add}}_i$ 和 $\tilde{\text{mult}}_i$ 都可以被高效地求值。

这段文本探讨了当电路的布线函数 $\tilde{\text{add}}_i$ 和 $\tilde{\text{mult}}_i$ 无法在 $O(\log S)$ 时间内直接高效求值时，学术界提出的几种经典的应对策略与解决方案。
