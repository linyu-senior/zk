### 4.5.2 A Useful Subroutine: Reducing Multiple Polynomial Evaluations to One(一个有用的子程序：将多次多项式求值归约（化简）为一次)

在刚才介绍的三角形计数协议中，协议结束时验证者需要在三个点处评估 $\tilde{f}_A$：即 $(r_1, r_2)$、$(r_2, r_3)$ 和 $(r_1, r_3)$。事实证明这种情况非常普遍：求和检验协议经常应用于某个多项式 $g$，使得为了在单个点处评估 $g$，有必要在多个点处评估某个其他的多线性多项式 $\tilde{W}$。

为了具体起见，我们首先假设 $\tilde{W}$ 是在有限域 $\mathbb{F}$ 上包含 $\log n$ 个变量的多线性多项式，并且验证者希望仅在**两个点**（不妨记为 $b, c \in \mathbb{F}^{\log n}$）处评估 $\tilde{W}$ —— 本节末尾我们将考虑三个或更多个点的情况。

我们将介绍一个简单的**单轮交互式证明**，其通信成本为 $O(\log n)$，它能够**将评估 $\tilde{W}(b)$ 和 $\tilde{f}(c)$ 归约为仅评估单个点 $r \in \mathbb{F}^{\log n}$ 处的 $\tilde{W}(r)$**。

这意味着，该协议将迫使证明者 $P$ 发送针对 $\tilde{W}(b)$ 和 $\tilde{W}(c)$ 的宣称值 $v_0$ 和 $v_1$，以及验证者 $V$ 以特定方式挑选的许多其他点处的宣称值。然后，$V$ 将从这些点中随机挑选一个 $r$。只要 $P$ 关于 $\tilde{W}(r)$ 的宣称是有效的，对 $V$ 来说**相信 $v_0 = \tilde{W}(b)$ 且 $v_1 = \tilde{W}(c)$ 就是安全（可靠）的**。

换句话说，该协议将确保：如果 $v_0 \neq \tilde{W}(b)$ 或 $v_1 \neq \tilde{W}(c)$ 中有任意一个成立（即 Prover 作假），那么在 $V$ 对 $r$ 的随机选择下，以极高的概率，**证明者针对 $\tilde{W}(r)$ 的值也必将做出虚假宣称**。

**_协议_**。
设 $\ell : \mathbb{F} \to \mathbb{F}^{\log n}$ 是穿过 $b$ 和 $c$ 的某条规范直线。例如，我们可以让 $\ell: \mathbb{F} \to \mathbb{F}^{\log n}$ 成为满足 $\ell(0) = b$ 且 $\ell(1) = c$ 的唯一直线。证明者 $P$ 发送一个次数至多为 $\log n$ 的一元多项式 $q$，该多项式被宣称是 $\tilde{W} \circ \ell$（即 $\tilde{W}$ 限制在直线 $\ell$ 上的函数）。验证者 $V$ 将 $q(0)$ 和 $q(1)$ 解释为证明者关于 $\tilde{W}(b)$ 和 $\tilde{W}(c)$ 取值的宣称值 $v_0$ 和 $v_1$。$V$ 从 $\mathbb{F}$ 中随机选择一个点 $r^* \in \mathbb{F}$，令 $r = \ell(r^*)$，并将 $q(r^*)$ 解释为证明者关于 $\tilde{W}(r)$ 取值的宣称。

**图示与示例**。
该技术在图 4.7 中进行了图解。为了给该技术的工作原理提供一个具体示例，假设 $\log n = 2$，$b = (2,4)$，$c = (3,2)$，且 $\tilde{W}(x_1,x_2) = 3x_1x_2 + 2x_2$。那么满足 $\ell(0) = b$ 且 $\ell(1) = c$ 的唯一直线 $\ell(t)$ 为 $t \mapsto (t + 2, 4 - 2t)$。$\tilde{W}$ 在 $\ell$ 上的限制为：

$$3(t + 2)(4 - 2t) + 2(4 - 2t) = -6t^2 - 4t + 32$$

如果 $P$ 发送一个被宣称等于 $\tilde{W} \circ \ell$ 的二次一元多项式 $q$，验证者将分别把 $q(0)$ 和 $q(1)$ 解释为关于 $\tilde{W}(b)$ 和 $\tilde{W}(c)$ 取值的宣称。接着，验证者将从 $\mathbb{F}$ 中随机选择一个 $r^*$，令 $r = \ell(r^*)$，并将 $q(r^*)$ 解释为 $\tilde{W}(r)$ 的宣称值。观察可知，$\ell(r^*) = (r^*+2, 4 - 2r^*)$ 是直线 $\ell$ 上的一个随机点。

接下来的断言（Claim）确立了上述协议的完备性（Completeness）与可靠性（Soundness）。

**_断言 4.6_**。
设 $\tilde{W}$ 是有限域 $\mathbb{F}$ 上包含 $\log n$ 个变量的多线性多项式。若 $q = \tilde{W} \circ \ell$，则对所有 $r^* \in \mathbb{F}$，均有 $q(0) = \tilde{W}(b)$、$q(1) = \tilde{W}(c)$ 且 $q(r^*) = \tilde{W}(\ell(r^*))$。反之，若 $q \neq \tilde{W} \circ \ell$，则在随机选择的 $r^* \in \mathbb{F}$ 下，以至少 $1 - \frac{\log n}{\vert{}\mathbb{F}\vert{}}$ 的概率满足 $q(r^*) \neq \tilde{W}(\ell(r^*))$。

**证明**。
第一部分由 $\ell(0)=b$ 和 $\ell(1)=c$ 的事实直接得出。对于第二部分，观察可知 $q$ 和 $\tilde{W} \circ \ell$ 都是次数至多为 $\log n$ 的一元多项式。若它们不是同一个多项式，那么根据 **Schwartz-Zippel 引理**（甚至是其针对一元多项式的简单特例），当 $r^*$ 从 $\mathbb{F}$ 中随机选择时，$q(r^*) \neq \tilde{W}(\ell(r^*))$ 的概率至少为 $1 - \frac{\log n}{\vert{}\mathbb{F}\vert{}}$。

这段内容把我们刚才“连线降维”的思想做了一个非常自然的推广：**如果需要求值的点从 2 个变成了 3 个（或更多），我们只需要把“直线”升级为“曲线”即可！**

我们先把它直译过来，再来看看它是怎么用一条二次曲线把 3 个点完美串起来的。

**_将三个或更多次求值归约为一次_**。
如果验证者需要在两个以上的点处评估 $\tilde{W}$，类似的协议依然适用。例如，假设验证者需要知道 $\tilde{W}(a)$、$\tilde{W}(b)$ 和 $\tilde{W}(c)$。这一次，我们让 $\ell$ 成为一条穿过 $a$、$b$ 和 $c$ 的规范二次曲线。为了具体起见，我们可以让 $\ell$ 成为满足 $\ell(0) = a$、$\ell(1) = b$ 且 $\ell(2) = c$ 的唯一二次曲线。例如，如果 $a = (0,1)$、$b = (2,2)$ 且 $c = (8,5)$，那么 $\ell(t) = (2t^2, t^2 + 1)$。
