**_求和检验协议的实例执行_**。设 $g(X_1, X_2, X_3) = 2X_1^3 + X_1X_3 + X_2X_3$。多项式 $g$ 在布尔超立方体上的评估值之和为 $H = 12$。当对 $g$ 应用求和检验协议时，协议中诚实证明者的第一条消息是一元多项式 $s_1(X_1)$，它等于：

$$g(X_1,0,0) + g(X_1,0,1) + g(X_1,1,0) + g(X_1,1,1) = (2X_1^3) + (2X_1^3 + X_1) + (2X_1^3) + (2X_1^3 + X_1 + 1) = 8X_1^3 + 2X_1 + 1$$

验证者检查 $s_1(0) + s_1(1) = 12$，然后向证明者发送 $r_1$。假设 $r_1 = 2$。接着，诚实证明者将回应一元多项式：

$$s_2(X_2) = g(2, X_2, 0) + g(2, X_2, 1) = 16 + (16 + 2 + X_2) = 34 + X_2$$

验证者检查 $s_2(0) + s_2(1) = s_1(r_1)$，在本例中即确认 $34 + (34 + 1) = 8 \cdot (2^3) + 4 + 1$；事实上，等式左边和右边都等于 69。随后，验证者向证明者发送 $r_2$。假设 $r_2 = 3$。诚实证明者将回应一元多项式：

$$s_3(X_3) = g(2, 3, X_3) = 16 + 2X_3 + 3X_3 = 16 + 5X_3$$

并且验证者通过确认 $s_3(0) + s_3(1) = s_2(r_2)$，在本例中即确认 $16 + 21 = 37$。验证者挑选一个随机域元素 $r_3$。假设 $r_3 = 6$。验证者通过对 $g$ 进行一次预言机查询，确认 $s_3(6) = g(2, 3, 6)$。

**_完备性与可靠性。_** 以下命题形式化了求和检验协议的完备性与可靠性性质。

**_命题 4.1_**。设 $g$ 是一个在有限域 $\mathbb{F}$ 上定义的 $v$ 元多项式，每个变量的最高次数不超过 $d$。对于任意指定的 $H \in \mathbb{F}$，设 $L$ 为满足以下条件的多项式 $g$（以预言机形式给出）的语言类：

$$H = \sum_{b_1 \in \{0,1\}} \sum_{b_2 \in \{0,1\}} \dots \sum_{b_v \in \{0,1\}} g(b_1, \dots, b_v)$$

求和检验协议是语言 $L$ 的一个交互式证明系统，其完备性误差 $\delta_c = 0$，可靠性误差 $\delta_s \le \frac{v \cdot d}{\vert{}\mathbb{F}\vert{}}$。

**_证明_**。完备性是显而易见的：如果在所有轮次 $j$ 中，证明者都发送了规定的多项式 $g_j(X_j)$，那么验证者 $V$ 将以概率 $1$ 接受。我们提供了两种关于可靠性的证明，第一种的推理方式类似于协议的迭代描述，第二种的推理方式类似于递归描述。

**_非归纳法可靠性证明。_** 概念上，证明可靠性的一种方法遵循求和检验协议的迭代描述。具体而言，如果 $H \neq \sum_{(x_1, \dots, x_v) \in \{0,1\}^v} g(x_1, x_2, \dots, x_v)$，那么证明者能够说服验证者接受的**唯一途径**是：存在至少某一个轮次 $i$，使得证明者发送了一元多项式 $g_i(X_i)$，该多项式**并不等于**规定的多项式

$$s_i(X_i) = \sum_{(x_{i+1}, \dots, x_v) \in \{0,1\}^{v-i}} g(r_1, r_2, \dots, r_{i-1}, X_i, x_{i+1}, \dots, x_v)$$

然而却**恰好满足**了 $g_i(r_i) = s_i(r_i)$。

对于每一个轮次 $i$，$g_i$ 和 $s_i$ 的次数最高都只有 $d$。因此，如果 $g_i \neq s_i$，那么 $g_i(r_i) = s_i(r_i)$ 的概率**最多为 $d/\vert{}\mathbb{F}\vert{}$**。通过对所有 $v$ 个轮次应用联合边界（Union Bound），存在任何一个轮次 $i$ 使得证明者发送了一个多项式 $g_i \neq s_i$ 却依然满足 $g_i(r_i) = s_i(r_i)$ 的概率**最多不超过 $dv/\vert{}\mathbb{F}\vert{}$**。
